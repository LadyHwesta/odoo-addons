# eLearning: Performer Events Training

One course for the Performer Events add-on, built into Odoo's eLearning app
on install (members only, by invitation, for event users), with a quiz:
**Your Own Events: Paying Talent and the Door**: performer fees and staff
hours billed as draft vendor bills, the 1099-NEC marking, and checking
people in at the door from the Point of Sale.

Its data is built by `performers_elearning/tools/build_course_data.py`.
