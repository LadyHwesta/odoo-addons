# Gig Gear Checklist

A packing checklist on every gig, filled from the packages you sold.
Needs **Gig Bookings** (`sale_gig_booking`).

## Set up

1. **Sales > Configuration > Gear**: add your gear (speakers, lights, mics,
   cables...), its category, and how many of each you own. A note (for
   example which case it lives in) shows on the checklist.
2. On each package or add-on product, the **Gigs** tab's **Gig Gear** list has the gear it
   needs and how many.

## On a gig

- Confirming a gig fills its **Gear** tab from the booked products. If two
  products each need 2 speakers, the gig needs 4.
- **Add Gear from Packages** adds anything new (after you add an add-on, for
  example). It never removes items or lowers quantities, so things you added
  by hand stay.
- Tick **packed** as things go in the van: "5 of 12 packed". **Untick All**
  starts over.
- A gig needing more of something than you own is flagged in red.
- **Print > Load-in Sheet** lists the gear by category, with boxes to tick.

## Access

Salespeople can see the gear list and work the checklists. Sales
administrators can change the gear list and each package's gear.
