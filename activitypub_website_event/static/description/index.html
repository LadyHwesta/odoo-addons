ActivityPub — Website Events

Publish events to the Fediverse as Event objects

What it does

Adds Federate events as to the event category (event.type); every event inherits it and can override it. Publishing an event on the website sends a Create, editing its dates / description / location / tags sends an Update, unpublishing or deleting it sends a Delete.

The Event object carries startTime / endTime, the venue as a Place (with latitude / longitude when the address is geolocated), the cover image, and the event tags — the shape Mobilizon and Gancio consume.

Requires

The ActivityPub Federation engine module and Website Events. Configure at least one actor first (Fediverse → Actors).
