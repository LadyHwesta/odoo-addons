Email Templates Menu

Edit email templates from Settings, without developer mode

What it does

Odoo's Email Templates screen is simple once you are on it, but the menu to reach it is under Settings, Technical, which needs developer mode.

This module adds a plain Email Templates menu directly under Settings, for anyone with Odoo's own Mail Template Editor permission.

A normal front door

Email Templates sits next to General Settings.

No new permissions

It uses Odoo's existing Mail Template Editor group.

No developer mode

Staff edit wording without turning on developer mode.

Setting it up

  1. Give the person the Mail Template Editor permission on their user.
  2. They open Settings, Email Templates.
