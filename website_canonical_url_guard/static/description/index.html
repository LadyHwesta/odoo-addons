Canonical URL Guard

Bots probing odd addresses get a plain 404, not a server error

What it does

Odoo 19 builds each page's canonical link with a strict URL check. Bots probing addresses such as /a/%2e%2e/etc/passwd make that check fail, so the "page not found" page itself crashes: visitors get a server error and your log an error.

This module falls back to your home page as the canonical link for those addresses, so the 404 page shows normally.

Quiet logs

No more "Couldn't render a template for http status 404" errors from bot traffic.

Normal pages unchanged

Real pages keep their usual canonical link.

Installs itself

It installs automatically with the Website app.

Setting it up

  1. Install it; there is nothing to set up.
