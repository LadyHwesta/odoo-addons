# eLearning: Getting Paid and Keeping the Books

One course for invoicing users, built into the eLearning app on install
(members only, by invitation), with a quiz and screenshots from a sample
business ("Redwood Print Co."):

- **Getting paid**: payment reminders, customer statements.
- **The bank**: importing a bank statement file (CSV or Excel), reconciling.
- **Reports and closing**: trial balance and other financial reports, fiscal
  years, lock dates, assets, journal entry templates.

It teaches Odoo Community with OCA's accounting apps (financial reports,
partner statements, statement import, reconciliation, fiscal years, lock
dates, assets, move templates). Every Managed Odoo suite includes it.

The data file is built by `tools/build_course_data.py`: edit the lesson there
and rerun it when a screen changes. Screenshots are in `static/img`.
