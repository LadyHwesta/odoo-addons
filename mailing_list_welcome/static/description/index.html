Mailing List Welcome

A welcome email for each new website newsletter signup

What it does

Pick an Email Marketing mailing as a list's welcome email. Everyone who signs up through a website newsletter block then gets it once.

Sent once

Each new subscriber gets the welcome email one time.

Unsubscribe built in

It carries Odoo's normal unsubscribe link and one-click unsubscribe headers.

Protects the owner

If someone signs up an address that isn't theirs, its owner can leave with one click.

Setting it up

  1. Write the welcome email as a mailing in Email Marketing.
  2. On the mailing list, choose it as the Welcome Email.
