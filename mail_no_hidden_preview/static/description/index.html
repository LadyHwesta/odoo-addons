No Hidden Email Preview

Remove the hidden preview text spam filters score against

What it does

Odoo's notification emails start with a hidden block of preview text padded with invisible characters. Spam filters such as SpamAssassin count that as a spammer trick.

This module empties that block, so inboxes preview the start of the message itself.

Fewer spam points

Removes a rule worth half of the score that marks mail as spam.

Better previews

Inbox previews show the message itself.

Mailings untouched

Email Marketing's own preview text field is left alone.
