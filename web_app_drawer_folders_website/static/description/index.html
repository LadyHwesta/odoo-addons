App Folders: Website

Your app folders in the apps menu on website pages

What it does

Signed-in staff see an apps menu at the top of website pages. With this module it shows the same folders and order as the backend, from App Folders and Order.

Same folders everywhere

Folder headings and your app order in the website apps menu.

Nothing to set up

It follows the folders you set in App Folders and Order.

Setting it up

  1. Install it next to App Folders and Order and Website; there is nothing else to set.
