Security Dashboard

A threat level, failed logins and blocks in the Dashboards app

What it does

Adds a Security dashboard to the Dashboards app, built on Security Auth Guard.

Threat level

One reading of how much attention logins need today.

At a glance

Failed logins, blocks and events waiting for review.

Setting it up

  1. Install it next to Security Auth Guard, and open Dashboards, Security.
