Security Auth Guard

Login attempts on record, and repeat attackers blocked for good

What it does

Odoo slows down repeated failed logins, but only in memory: the count is lost on every restart, and the block is always temporary.

This module keeps every login attempt on record, logs security events, and blocks an address for good once it keeps attacking.

Every login on record

Successful and failed logins, with address and login name, kept and reportable.

Permanent blocks

An address that triggers Odoo's slowdown too often in a day is blocked, before any page runs.

Allow and block lists

Add your own allowed or blocked addresses.

One security log

Events in a Security app, by severity, to review.

Setting it up

  1. Install it, then open the Security app.
  2. Set how many slowdowns in a day lead to a permanent block in its settings.
