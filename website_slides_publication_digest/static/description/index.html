eLearning Lesson Digest

One email per course for new lessons, not one per lesson

What it does

Odoo announces a lesson to the course's members whenever it is saved as published, even when it already was. Courses installed as modules are saved again on every update, so each update emailed every lesson again.

Only real news

A lesson is announced only when it becomes published.

One digest per course

Lessons added by a module install or update go out as one message per course, with links.

By hand, as before

Publishing a lesson yourself still sends its normal announcement.

Setting it up

  1. Install it; there is nothing to set up.
